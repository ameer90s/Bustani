بستاني - تطبيق زراعي (PWA)
=============================
كل الملفات في مجلد واحد بدون مجلدات فرعية. ارفعها كلها مع بعض:
  index.html, manifest.webmanifest, sw.js
  icon-192.png, icon-512.png, maskable-512.png, apple-touch-icon.png

مهم: التثبيت على التلفون يتطلب رابط https. ارفع الملفات على استضافة مجانية:
  Netlify Drop:  app.netlify.com/drop  (اسحب الملفات، يعطيك رابط https)
  أو Cloudflare Pages / GitHub Pages

التثبيت:
  أندرويد (كروم): القائمة (ثلاث نقاط) ثم "تثبيت التطبيق".
  آيفون (سفاري): زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".

إضافة نباتات: تاب "زراعتي" ثم زر "+ إضافة" (الاسم، اللون، فترة السقي صيفاً وشتاءً).

فحص الصور: تاب "اعرف شجرتك" ثم أدخل مفتاح Anthropic API مرة واحدة
  (من console.anthropic.com). يُحفظ في التلفون فقط، وكل فحص يُحسب على حسابك.

ملاحظات:
  - سجل السقي والنباتات المضافة تتحفظ داخل التلفون نفسه.
  - الخط يتحمل أول مرة من الإنترنت ثم يتخزن.
  - لو عدلت ملف، غيّر VERSION في sw.js ليتحدث التطبيق.
